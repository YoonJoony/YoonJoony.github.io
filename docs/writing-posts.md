# 글 작성 안내

## 1. 글을 둘 폴더 선택

`src/content/blog/DE Map`, `BE Map`, `Project Map`, `Blog` 중 하나에 Markdown 또는 MDX 파일을 만듭니다.
원하는 만큼 하위 폴더를 만들 수 있습니다. 폴더 위치가 Posts의 카테고리가 됩니다.
이미지만 들어 있는 폴더는 카테고리로 표시하지 않습니다.

## 2. 글 정보 입력

아래 예시의 날짜·slug·이미지 경로를 글에 맞게 바꿉니다.

```md
---
title: "파이썬 가상환경 만들기"
description: "프로젝트마다 독립적인 실행 환경을 준비하는 방법을 정리합니다."
pubDate: 2026-09-29
slug: python-virtual-environment
tags: [Python, Study]
draft: true
---

## 가상환경이 필요한 이유

여기부터 본문을 작성합니다.
```

- `title`, `description`, `pubDate`, `slug`는 필수입니다.
- `slug`는 소문자 영문·숫자·하이픈으로 만든 고유 이름입니다. 공개 후 유지하세요.
- `tags`는 선택입니다. `ML`, `ml`, `#ML`은 같은 필터로 취급합니다.
- `draft: true`는 사이트에 표시하지 않습니다. 공개할 준비가 되면 `false`로 바꿉니다.
- 수정일이 필요하면 `updatedDate: 2026-10-01`처럼 추가합니다.
- 파일을 옮겨도 slug가 같으면 주소는 유지됩니다. 상대 이미지 경로는 새 위치에 맞게 바꾸세요.
- 제목은 화면에서 한 번 표시되므로 본문은 보통 `##`부터 시작합니다.

## 3. 사진 추가

대표 사진은 글 정보에 한 줄을 추가합니다. 경로는 그 Markdown 파일 기준입니다.

```yaml
heroImage: ./images/cover.jpg
```

대표 사진을 생략하면 `src/assets/default-post-cover.png`를 사용합니다.
본문 사진은 원하는 위치에 아래처럼 작성합니다.

```md
![가상환경 생성 결과](./images/venv-result.png)
```

이미지 파일도 함께 Git에 추가해야 합니다.

## 4. 폴더 안에서 읽는 순서

같은 폴더의 모든 파일 이름이 `01_`, `02_`, `10_`처럼 숫자로 시작하면 숫자순으로 나옵니다.
그 외에는 발행일 최신순입니다. 같은 날짜는 slug로 순서를 고정합니다.
수동 순서가 필요하면 같은 폴더의 모든 글에 `order: 1` 같은 정수를 지정합니다.
메인의 Recent blog posts는 항상 발행일 최신순입니다.

## 5. 확인하고 발행

```sh
npm run check
npm test
npm run build
```

본문이 없는 공개 글, 중복 slug, 잘못된 날짜·이미지 경로는 수정해야 빌드할 수 있습니다.
초안은 사이트 출력에서 제외됩니다. GitHub 저장소가 공개라면 커밋한 초안 파일 자체는 저장소에서 볼 수 있습니다.

## 6. News Research

`src/content/news`에 아래 정보가 있는 Markdown을 추가합니다.

```yaml
---
title: "실제 뉴스 제목"
description: "직접 작성하거나 검토한 뉴스 요약"
pubDate: 2026-09-29T09:00:00+09:00
sourceName: "원문 매체 이름"
sourceUrl: https://example.com/actual-article
tags: [경제, IT]
draft: true
---
```

예시 주소는 실제 원문 주소로 바꾸세요.
`draft: false`인 뉴스 중 최신 3개만 메인에 표시하고, 클릭하면 해당 원문으로 이동합니다.
이미지에는 개인 글과 같은 `heroImage` 규칙을 사용합니다.
개인 글의 카테고리·태그 목록과 RSS에는 뉴스가 섞이지 않습니다.
자동 수집·요약·발행과 블로그 내부의 뉴스 상세 페이지는 아직 구현하지 않았습니다.

## 7. Python 실행 예제

코드 편집기와 실행 버튼이 필요한 글은 `.mdx`로 작성합니다.
CSV 등록, 표·그래프 출력, 초기화 방법은 [Python 실습 작성 안내](./python-playground.md)를 참고하세요.

## 8. 메인 공지사항

일반 Markdown/MDX 글의 `tags`에 **`공지사항`**을 추가하면 됩니다.
예를 들어 `src/content/blog/Blog/공지사항/블로그_이용_안내.md`에 작성할 수 있습니다.

```yaml
---
title: "블로그 이용 안내"
description: "글 탐색과 Python 실습 기능을 소개합니다."
pubDate: 2026-10-04
slug: blog-guide
tags: [Blog, 공지사항]
draft: true
---
```

본문을 작성한 뒤 `draft: false`로 바꾸고 배포하면, 메인 소개 아래에 제목이 표시됩니다.

- 모든 카테고리에서 공지를 찾고, `pubDate` 기준 최신 3개를 보여 줍니다.
- `#공지사항`도 인식하지만 `공지`나 `알림`은 다른 태그입니다.
- 제목을 누르면 해당 글로 이동합니다. 공지는 Posts·최근 글·RSS에도 기존 규칙대로 나옵니다.
- 제목이 한 줄에 들어오면 정지하고, 넘칠 때만 왼쪽으로 천천히 이동합니다.
- 마우스를 올리면 잠시 멈춥니다. `멈춤` 버튼, 키보드 초점, 터치로 수동 읽기로 전환할 수 있습니다.
- 모바일에서는 옆으로 밀어 읽을 수 있습니다. 모션 줄이기 설정에서는 자동으로 움직이지 않습니다.
- 공개 공지가 없으면 영역 전체가 숨겨집니다. 공지에서 내리려면 태그를 제거한 뒤 다시 배포하세요.

디자인 수치, 관련 파일, 동작 기준은 [공지사항 개발 설계](./notice-bar-spec.md)를 참고하세요.
