## Pandas의 데이터 구조

### 1) 시리즈(Series)
시리즈 클래스는 1차원 배열의 값에 각 값에 대응되는 인덱스를 부여할 수 있는 구조  
```py
sr = pd.Series([17000, 18000, 1000, 5000],
            index=["피자", "치킨", "콜라", "맥주"])
print(sr)
```
```shell
#시리즈 출력
피자    17000
치킨    18000
콜라     1000
맥주     5000
```

값과 인덱스만 출력
```py
print(f'시리즈의 값 : {sr.values}')
print(f'시리즈의 인덱스 : {sr.Index}')
```
```shell
시리즈의 값 : [17000, 18000, 1000, 5000]
시리즈의 인덱스 : Index(['피자', '치킨', '콜라', '맥주'], dtype='object')
```

### 2) 데이터프레임
2차원 리스트를 매개변수로 전달한다.  
행과 열을 가지는 자료구조  

시리즈가 인덱스와 열로 구성된다면 데이터 프레임은 열이 추가되어 열, 인덱스, 값으로 구성됨  

```py
values = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
index = ['one', 'two', 'three']
columns = ['A', 'B', 'C']

df = pd.Dataframe(values, index=index, columns=columns)
```
```shape
       A  B  C
one    1  2  3
two    4  5  6
three  7  8  9
```

데이터 프레임의 인덱스와 값(values), 열(columns) 출력
```py
print(f'데이터프레임의 인덱스 : {df.index}')
print(f'데이터프레임의 열이름 : {df.column}')
print(f'데이터프레임의 값 : {df.values}')
```
```shape
데이터프레임의 인덱스 : Index(['one', 'two', 'three'], dtype='object')
데이터프레임의 열이름: Index(['A', 'B', 'C'], dtype='object')
데이터프레임의 값 :
------------------
[[1 2 3]
 [4 5 6]
 [7 8 9]]
```

## 2. 넘파이(Numpy)

```py
import numpy as np
```

### 1. np.array()
Numpy의 핵심. np.array()는 리스트, 투플, 배열로부터 array를 생성한다. 파이썬 자료구조 중 하나인 리스트를 Numpy 배열로 생성
```py
vec = np.array([1, 2, 3, 4, 5])
```
```shell
[1 2 3 4 5]
```

2차원 배열 생성  
```py
mat = np.array([[10, 20, 30], [60, 70, 80]])
```
```shell
[[10 20 30]
 [60 70 80]]
```

### 2. ndim, shape
넘파이는 축의 개수(ndim)와 크기(reshape)라는 개념이 존재.  
배열의 크기를 정확히 숙지하는것은 딥 러닝에서 매우 중요  
```py
print(f'mat 축 개수 : {vec.ndim}')
print(f'mat 크기 : {vec.shape}')
```
```shell
vec의 축의 개수 : 2
vec의 크기(shape) : (2, 3)
```

### 3. ndarry의 초기화

`np.zeros()`는 지정한 크기의 배열의 모든 원소에 0을 추가한다
```py
zero_mat = np.zeros((2, 3))
```
```shell
[[0. 0. 0.]
 [0. 0. 0.]]
```

`np.ones()`는 지정한 크기의 배열의 모든 원소에 1을 추가한다
```py
one_mat = np.zeros((2, 3))
```
```shell
[[1. 1. 1.]
 [1. 1. 1.]]
```

`np.full()`는 지정한 크기의 배열의 모든 원소에 1을 추가한다
```py
same_value_mat = np.full((2, 2), 7)
```
```shell
[[7 7]
 [7 7]]
```

`np.random.random()`은 임의의 값을 가지는 배열을 생성
```py
random_mat = np.random.randon(2, 2)
```
