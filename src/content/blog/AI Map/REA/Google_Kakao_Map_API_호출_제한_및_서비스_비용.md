# Google·카카오 API 호출 및 비용 정리

기준일: 2026-10-18 · 대상: 현재 배포된 karrot-demo 웹 앱

> 홈 지도에 처음 들어가면 보통 **지도 표시 1회 + 주변 매장 검색 1회**가 발생한다. 이후 검색 조건을 바꾸거나 매장 상세·사진을 보면 추가 호출된다. **방문자 수와 API 호출 수는 같지 않다.**

이 문서는 현재 코드와 공식 요금표를 정리한 설명 자료다. 실제 월 청구서나 호출량을 측정한 보고서는 아니며, 아래 개선 사항은 아직 구현하지 않았다.

Map API는 구글+카카오 API 이다.
구글은 맵 표시, 주변 매장 검색, 키워드 매장 검색, 매장 상세(후기, 사진) 목적 (각 항목마다 비용과 무료 호출 제한 다름)
카카오는 현재 좌표를 행정동 구역으로 변환시 목적.

### 0. 필독
> 구글+카카오 API로 한 이유는 매장의 상세 정보를 제공해주기 위함 (후기, 별점, 사진 등)
> 카카오, 네이버 API는 이러한 상세 항목이 호출되지 않는다. 
> 따라서 굳이 매장의 상세정보 없이 매장만 불러오는걸 원하면 굳이 구글 API를 사용할 필요는 없음. 
가성비도 국내 API에 비해 떨어지고. 매장 종류, 지리적 정확도도 국내가 더 좋음.

## 1. 서버와 API 역할

현재 서버는 **Sites를 통해 배포한 Cloudflare Workers**다. 요청이 들어오면 코드를 실행하는 서버리스 방식이며, 기존 Expo 웹 화면과 API를 제공한다.

| 역할 | 사용 서비스 | 쉬운 설명 |
| --- | --- | --- |
| 지도 표시 | Google Maps JavaScript API | 도로·건물·지도 배경을 보여 줌 |
| 주변·키워드 검색 | Google Places API | 동물병원·반려용품점 등 매장 목록을 찾음 |
| 매장 상세 | Google Place Details | 전화번호·평점·영업시간·후기를 가져옴 |
| 매장 사진 | Google Place Photos | 사진 이미지를 가져옴. 상세 조회와 별도 계산 |
| 좌표 → 행정동 | 카카오 REST API | 선택한 좌표가 어느 동네에 속하는지 확인 |

- 여기서 **매장 상세**는 Google, **행정동 확인**은 카카오다. 현재 카카오 지도 화면이나 카카오 매장 검색은 사용하지 않는다.
- Google 지도 표시용 키와 서버용 Places 키는 분리돼 있다. 카카오 REST 키도 서버에만 보관한다.
- DB·파일 저장소·실시간 채팅 서버는 아직 없다. 아래 금액은 API 비용이며 호스팅·DB·저장소 비용은 별도다.

## 2. 사업자용 새 키를 만들면 요금이 달라지나?

**키를 새로 발급하거나 사업자 명의로 사용한다는 사실만으로 할인·무제한 무료가 적용되지는 않는다.** 사용하는 API, 무료량 적용 조건, 실제 호출량, 별도 계약에 따라 계산한다.

- **Google:** 별도 구독·기업 계약이 없는 종량제 기준으로 아래 표를 적용한다. 같은 결제 계정의 프로젝트 사용량을 함께 보므로, 새 키마다 무료량이 추가된다고 계산하면 안 된다.
- **카카오:** 개발자 계정에서 카카오맵을 **첫 번째로 활성화한 앱에만 무료 쿼터**가 적용된다. 두 번째 이후 앱 또는 무료량을 넘겨 사용할 앱은 비즈월렛 연결·유료 API 설정이 필요하다. 새 사업자용 앱 생성 시 무료 적용 여부부터 확인한다.

출처: [Google 과금 기준](https://developers.google.com/maps/billing-and-pricing/pricing), [카카오 이용 정책](https://developers.kakao.com/docs/ko/kakaomap/common).

## 3. Google 요금

현재 웹 구조의 종량제 기준이다. 무료량은 항목별로 적용하며, 단가는 각 항목 **월 10만 회까지**의 구간이다. 그 이상은 단계별 할인이 적용된다.

| 기능 | 월 무료량 | 무료량 초과 후 1,000회당 |
| --- | ---: | ---: |
| 웹 지도 표시 — Dynamic Maps | 10,000회 | $7 |
| 주변 매장 검색 — Nearby Search Pro | 5,000회 | $32 |
| 키워드 매장 검색 — Text Search Pro | 5,000회 | $32 |
| 매장 상세: 후기 포함 — 현재 코드 | 1,000회 | $25 |
| 매장 상세: 후기 제외, 전화·평점·영업시간 유지 — 변경 시 | 1,000회 | $20 |
| 매장 사진 — Place Details Photos | 1,000회 | $7 |

현재 상세 요청에는 `reviews`가 포함돼 **Enterprise + Atmosphere** 등급이 적용된다. Enterprise는 사업자 계정이라는 뜻이 아니라 요청 정보의 요금 등급이다. 요청한 필드 중 가장 높은 등급으로 계산하며, 각 등급 요금을 모두 더하는 방식은 아니다.

검색·상세 응답에서 사진의 이름/참조 정보를 받는 것과, 실제 사진 이미지를 가져오는 요청은 구분된다. **사진 이미지를 요청할 때 사진 요금이 별도로 발생한다.**

출처: [Google 공식 요금표](https://developers.google.com/maps/billing-and-pricing/pricing), [필드별 등급](https://developers.google.com/maps/documentation/places/web-service/data-fields), [요청 필드와 과금](https://developers.google.com/maps/documentation/places/web-service/usage-and-billing).

## 4. 카카오 요금

| 기능 | 무료 적용 대상 앱의 일간 한도 | 유료 호출 단가 |
| --- | ---: | ---: |
| 좌표 → 행정구역 — 현재 사용 | 100,000회 | 0.5원/회 |
| 키워드 장소 검색 — 향후 전환 시 | 100,000회 | 2원/회 |
| 카테고리 장소 검색 — 향후 전환 시 | 100,000회 | 2원/회 |

무료 이용에는 **전체 API 월간 300만 건 한도**도 고려해야 한다. 추가 유료 쿼터를 사용한 호출은 무료 월간 쿼터를 차감하지 않는다. 예를 들어 **유료로 계산되는 행정동 조회가 10만 건**이면 단가 계산상 5만 원이다. 전체 호출이 10만 건이라는 이유만으로 5만 원이 청구되는 것은 아니다.

카카오 무료량 초과 후 계속 사용하려면 유료 API 설정이 필요하다. 실제 적용량은 해당 앱의 쿼터·유료 설정에서 확인한다.

출처: [카카오 공식 쿼터·요금](https://developers.kakao.com/docs/ko/getting-started/quota).

## 5. 지금 앱에서 언제 추가 호출되나?

아래의 지도 횟수는 전체 네트워크 요청 수가 아닌 **과금 기준 지도 로드 횟수**다. 지도 파일·타일 등의 개별 통신 수와 다르다.

| 사용자 행동 | 지도 추가 로드 | 매장 검색 추가 호출 |
| --- | ---: | ---: |
| 처음 홈 지도 진입 | 1회 | 보통 1회 |
| 지도 드래그·확대·축소 | 없음 | 없음 |
| ‘이 지역에서 다시 검색’ | 없음 | 검색 위치가 바뀌면 1회 |
| 다른 동네로 탐색 지역 변경 | 없음 | 검색 위치가 바뀌면 1회 |
| 동물병원·반려용품 등 카테고리 변경 | 없음 | 변경할 때마다 1회 |
| 검색창에서 검색 실행 | 없음 | 키워드 검색 1회 |
| ‘동물 찾기 ↔ 주변 시설’ 전환 | 없음 | 기존 결과 재사용 |
| 글 목록·채팅 탭을 보고 홈으로 복귀 | 기본적으로 기존 지도 유지 | 검색 조건이 같으면 없음 |
| 브라우저 새로고침 | 다시 1회 | 다시 검색 |
| 동네 선택에서 ‘지도에서 고르기’ 열기 | 별도 지도이므로 추가 | 홈 매장 검색과 별개 |

- **첫 진입 검색이 반드시 1회인 것은 아니다.** GPS 확인이 8초를 넘기면 기본 동네로 먼저 검색하고, 뒤늦게 실제 위치를 얻으면 다시 검색할 수 있다.
- 한 번의 검색에서 매장 20곳이 반환돼도 검색 20회가 되는 것은 아니다.
- 같은 화면에서 조건이 유지되면 현재 결과를 쓰지만, 카테고리를 바꿨다가 돌아오면 다시 검색한다. 조건별 결과를 보관해 재사용하는 캐시는 없다.
- 동물 프로필·성별·품종 필터는 앱에 있는 글을 거르는 기능이므로 그 자체로 Google 매장 검색을 추가 호출하지 않는다.
- 카카오는 GPS·지도 좌표를 행정동으로 확인할 때 호출한다. 동네 이름 검색·주변 행정동 목록은 앱에 포함된 지역 데이터를 사용한다.

사진·상세는 위 검색 횟수와 따로 계산한다.

| 행동 | 추가되는 요청 |
| --- | --- |
| 홈에서 반려동물 프로필 사진 보기 | 샘플 이미지이므로 Google 매장 사진 요청 아님 |
| ‘주변 시설’ 목록 열기 | 처음 표시하는 최대 6개 카드의 대표 사진을 각각 요청할 수 있음 |
| 시설 목록 ‘더 보기’ | 이미 받은 검색 결과를 펼침. 추가 카드 사진 요청은 발생할 수 있음 |
| 시설 카드 선택 | 상세 요청 및 사진 요청. 상세 화면은 최대 10장 렌더링 |
| Google 지도 기본 가게 아이콘 선택 | 현재 상세 조회 후 패널에서 다시 조회하는 중복 경로가 있음 |
| 사진 탭·상세 확대 | 새 이미지나 다른 크기의 이미지 요청이 추가될 수 있음 |

이미지는 브라우저의 재사용 여부 등에 따라 실제 요청 수가 달라진다. 따라서 ‘매장 클릭 1회 = 사진 1회’로 계산하면 안 된다.

근거: `src/app/(tabs)/index.tsx`, `src/components/map/StoreMap.web.tsx`, `ExploreContent.tsx`, `PlaceSheet.tsx`, `src/hooks/useMyLocation.ts`. 지도 과금 기준: [Google 공식 설명](https://developers.google.com/maps/billing-and-pricing/sku-details#dynamic-maps).

## 6. 동물 관련 매장만 조회하면 얼마인가?

**동물 매장만 조회해도 1회당 단가는 같다.** 일반 식당·카페 등의 불필요한 요청을 없애 호출량을 줄이는 만큼 절약된다.

다음은 **현재처럼 후기 포함 상세 조회**를 사용하고 해당 월 무료량이 온전히 남아 있다고 가정한 계산이다. 사용자 수나 서로 다른 매장 수가 아니라 실제 API 요청 수 기준이다.

| 월 상세 요청 | 월 사진 요청 | 상세 + 사진 비용 | 원화 예시 |
| ---: | ---: | ---: | ---: |
| 1,000회 | 1,000회 | $0 | 0원 |
| 1,000회 | 10,000회 | $63 | 88,200원 |
| 10,000회 | 10,000회 | $288 | 403,200원 |
| 10,000회 | 50,000회 | $568 | 795,200원 |

- 원화는 설명용 **1달러=1,400원** 가정이다. 실제 환율·세금은 별도다.
- **지도 표시·매장 검색·카카오·서버 비용은 위 표에 포함하지 않았다.**
- 계산식: `max(상세 요청−1,000, 0) × $0.025 + max(사진 요청−1,000, 0) × $0.007`.
- 예: 상세를 1,000번 열 때마다 사진 10장을 새로 요청하면 상세는 무료 범위여도 사진 10,000회 중 9,000회는 유료다.

공식 단가에서 무료량을 차감한 예시이며, 기존 결제 계정 사용량·별도 계약에 따라 실제 청구액은 달라질 수 있다.

## 7. 비용을 줄이려면 바꿀 부분 — 아직 미적용

현재 기본 시설 카테고리는 동물병원·반려용품·반려동물 미용이다. 다만 **지도 기본 가게 아이콘 클릭과 자유 검색에는 일반 업종이 들어오는 경로**가 남아 있다.

1. **조회 대상을 동물 시설로 제한:** 일반 가게 클릭 경로를 막고 자유 검색에도 업종 제한을 적용한다. 서버에서도 허용한 동물 시설의 상세·사진만 조회하도록 한다.
2. **사진은 필요한 만큼만:** 목록은 사진을 생략하거나 필요한 카드만 로딩하고, 상세는 대표 1장부터 보여 준다. 나머지는 사용자가 요청할 때 가져온다.
3. **후기는 기본 요청에서 제외:** 평점·전화·영업시간을 유지하면서 상세 단가를 $25 → $20/1,000회로 낮출 수 있다. 후기가 필요하면 탭을 열 때 별도 요청하되 추가 요청 비용도 계산한다.
4. **상세 중복 요청 제거:** 지도 기본 가게 선택 시 이미 받은 상세를 패널에서 다시 요청하지 않도록 한다.
5. **호출량 측정과 한도 적용:** 지도·검색·상세·사진·카카오 요청을 분리해 집계한다. 사진/상세 월 1,000회 전역 차단은 현재 구현돼 있지 않다.

권장 초기 구성은 **동물 시설만 조회 + 상세 대표 사진 1장 + 후기 기본 제외 + 중복 호출 제거**다. 현재 사이트는 전체 공개이므로 다른 방문자의 API 사용량도 운영자의 결제 계정에 합산될 수 있다.
