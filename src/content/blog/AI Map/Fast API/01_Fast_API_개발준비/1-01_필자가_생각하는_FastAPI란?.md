Fast API는 API를 만들기 위한 파이썬 웹 프레임워크이다. 이름에 걸맞는 빠른 속도를 자랑함.  

### 기존 프레임워크의 차이점
파이썬 웹 프레임워크 중 가장 유명한 장고와 플라스크는 주로 웹 서비스를 만들때 사용한다.  
하지만 FastAPI는 API를 만드는데 보다 집중한 프레임워크다.  

### 속도가 빠름

### 빠르게 작성 가능
API 개발은 보통 입출력 스펙정 정하고 기능을 구현한 후 테스트 하는 순서로 진행한다.

FastAPI는 입출력을 정의하고 입출력 값의 검증을 빠르고 안전하게 할 수 있다.

### 테스트 가능한 API 문서
FastAPI는 작성한 API 사용법에 관한 문서를 따로 작성할 필요가 없다. API 문서가 자동 시행된다.  
API 문서는 웹 페이지 형태로 제공되며 API 동작을 테스트할 수 있다.
