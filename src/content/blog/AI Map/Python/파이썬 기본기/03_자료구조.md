## 자료구조

### 데이터 엔지니어링 시 자주 사용하는 자료구조
> 여러 행은 list, 한 행 필드는 dick, 중복 확인은 set, 고정된 값의 조합은 tuple

### 각 자료구조 차이와 선택 기준
| 구분 | `list` | `dict` | `tuple` | `set` |
|---|---|---|---|---|
| 기본 형태 | `[값, 값]` | `{키: 값}` | `(값, 값)` | `{값, 값}` |
| 핵심 역할 | 순서가 있는 값의 목록 | 이름·키로 값을 찾는 구조 | 위치가 정해진 값의 묶음 | 중복 없는 값의 집합 |
| 순서 | 있음 | 삽입 순서 유지 | 있음 | 순서 보장 없음 |
| 중복 | 허용 | 키는 중복 불가, 값은 가능 | 허용 | 중복 원소 제거 |
| 내용 변경 | 가능 | 가능 | 원소 교체·추가·삭제 불가 | 원소 추가·삭제 가능 |
| 주된 조회 방법 | 위치 | 키 | 위치 | 포함 여부 |
| 대표 활용 | 주문 목록, 처리 결과 | 주문 한 건, 설정, 조회용 매핑 | 복합 키, 고정된 반환값 | 중복 ID 확인, 누락 비교 |

### 상황별 선택
| 하고 싶은 작업 | 적합한 구조 |
|---|---|
| API에서 받은 주문 100건을 순서대로 보관 | `list` |
| 주문 한 건의 ID·금액·상태를 이름으로 관리 | `dict` |
| 고객 ID로 고객 정보를 빠르게 찾기 | `dict` |
| 이미 처리한 주문 ID인지 확인 | `set` |
| 원본과 저장 결과에서 빠진 ID 찾기 | `set` |
| 고객 ID와 날짜를 하나의 키로 사용 | `tuple` |
| 최초 입력 순서를 유지하면서 중복 주문 제거 | `list`와 `set` 조합 |

### 1. list

| 목적 | 코드 | 결과·의미 |
|---|---|---|
| 한 개 추가 | `values.append("D")` | `["A", "B", "C", "D"]` |
| 여러 개 추가 | `values.extend(["D", "E"])` | `["A", "B", "C", "D", "E"]` |
| 특정 위치에 삽입 | `values.insert(1, "X")` | `["A", "X", "B", "C"]` |
| 값의 위치 조회 | `values.index("B")` | `1` |
| 값으로 삭제 | `values.remove("B")` | `["A", "C"]` |
| 꺼내면서 삭제 | `values.pop()` | `"C"` 반환, 목록에는 `["A", "B"]` |
| 특정 위치를 꺼내면서 삭제 | `values.pop(0)` | `"A"` 반환 |
| 위치로 삭제 | `del values[1]` | `["A", "C"]` |
| 모두 삭제 | `values.clear()` | `[]` |
| 정렬 | `value.sort() or sorted(value)` | `[3, 1, 2]` -> `[1, 2, 3]` |

`extend"(문자열)` 삽입 시 문자가 들어감

`value.sort()`는 원본 문자열만 정렬, `sorted(value)`는 원본 정렬은 유지하며 새 리스트에 사용 가능.

### 2. dict (선언, 교체, 삭제, 키 조회)

```py
    order = { 
        "order_name" : "아토베리어 로션",
        "amount" : 1000,
        "delivery_dt" : "2026-09-24"
    }

    # 여러 값을 교체
    order.update({
        "amount" : 1200,
        "delivery_dt" : "2026-09-29"
    })

    # 키 삭제
    del order["delivery_Dt"] # 키가 없으면 Error

    # 모두 삭제
    order.clear()

    # 키 조회 두 가지
    print(order["order_name"])      # 값이 없다면 KeyError
    print(order.get("order_name"))  # 값이 없다면 None
    print(order.get("order_name", "null")) # 값이 없다면 내부 문자열("null")
```

>`order.get(딕셔너리, 문자열)` 사용시 주의할 점.  
키가 없을 시 `문자열`을 반환하지 키가 존재하고 내부 값이 None이라면 None을 반환한다.

### dick 반복문으로 출력

```py
    # 그냥 반복돌리면 키가 나온다
    for key in order:
        print(key) # "order_name", "ammount", ...

    # 값만 조회
    for key in order:
        print(order[key])
    for key in order.keys():
        print(order[key])

    # 키, 값 조회
    for key, value in order.items():
        print(key)
        print(value)
```

| 메서드 | 제공하는 것 |
|---|---|
| `order.keys()` | 키들 |
| `order.values()` | 값들 |
| `order.items()` | `(키, 값)` 쌍들 |

### 3. tuple : 위치가 정해진 값의 묶음
```py
    # 투플 선언
    order_summary = ("0001", 1200, "paid")

    print(order_summary[0]) # 0001
    print(order_summary[1]) # 1200

    # 인덱스 슬라이싱, 반복 포함 여부 확인 가능
    print("paid" in order_summary) # True
    print(order_summary[:2]) # ("0001", 1200)

    # 원소 교체 불가능
    order_summary[1] = 1450 # TypeError
```

### tuple : 언제 사용?
- (고객 ID, 날짜) 처럼 여러 값을 하나의 키로 묶을 때
- 함수에서 여러 결과를 함께 반환 시
- 위치 별 의미가 명확한 작은 값 묶음을 표현할때

```py
    # 
    daily_total = {}

    key = ("C01", "2026-09-17")
    daily_total[key] = 1500

    print(daily_total[("C01", "2026-09-17")])
    # 1500
```

여러 값이 하나의 키로 묶을 시 문자열 보단 명확하게 구분하는 `tuple`을 사용

```py
    # 구분 핵심은 괄호가 아닌 쉼표
    a = ("0001")
    b = ("0001",)

    print(type(a))  # <class 'str'>
    print(type(b))  # <class 'tuple'>
```

### 4. set: 중복 없이 보관하고 집합으로 비교하기

**생성과 중복 제거**
```py
    order_ids = ["O001", "O002", "O001"]

    unique_ids = set(order_ids)

    print(len(unique_ids))      # 2
    print("O001" in unique_ids) # True
```

> 출력/순회 순서는 보장되지 않는다. 따로 정렬 필요

**추가/삭제**
