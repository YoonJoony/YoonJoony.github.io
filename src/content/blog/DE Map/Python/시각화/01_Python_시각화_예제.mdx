export const chartCode = `import pandas as pd
import matplotlib.pyplot as plt

# 저장소에 있는 학습용 CSV를 읽습니다.
df = pd.read_csv("/data/python-visualization/study-hours.csv")
print("학습 기록:", len(df), "일")
display(df)

# hours 값을 바꾸거나 색상을 바꾸고 다시 실행해 보세요.
plt.figure(figsize=(6, 3.6))

plt.title("요일별 Python 공부 시간")
plt.xlabel("요일")
plt.ylabel("시간")
plt.tight_layout()
plt.show()`;

## CSV를 읽고 그래프 그리기

아래 코드는 이미 입력되어 있습니다. **실행**을 누르면 표와 막대그래프가 순서대로 나타납니다.
CSV는 기능을 연습하기 위해 만든 가상 학습 기록입니다.

- `pd.read_csv(...)`: CSV 파일을 DataFrame으로 읽습니다.

## Series와 다차원 배열 살펴보기

Series는 인덱스가 붙은 한 열의 데이터입니다. 3차원 배열은 여러 장의 2차원 표로 나누어 볼 수 있습니다.
`display(...)`로 여러 결과를 출력하거나, 마지막 줄에 변수 이름만 적어도 결과가 나타납니다.
