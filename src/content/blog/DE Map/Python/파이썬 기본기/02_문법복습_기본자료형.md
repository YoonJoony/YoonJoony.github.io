## 기본 문법 자료형/제어문

### 1. 기본 자료형과 형 변환 (Data Types & Type Casting) + 제어문

- `int`, `float`:
    - Java와 달리 파이썬 int는 오버플로우가 없다. int와 long을 구분할 필요 없이 무한대의 정수를 처리한다.
    - 데이터 소스(CSV, API)에서 읽어온 숫자는 무조건 문자열(str)로 들어온다.  
    이를 연산 혹은 DB 입력을 위해 형 변환 작업이 필수다.  
    특히 금액 데이터 처리 시 소수점 오차가 발생할 수 있으므로, 정밀한 계산이 필요할때는 float대신 decimal 모듈을 쓰게 된다.
- `str` : 자바와 달리 홑따옴표('), 쌍따옴표(")로 구분하지 않고 똑같이 문자열로 취급됨
- `None` : null
    - DB에서 파이썬으로 NULL 값을 가져오면 None이 된다.  
    반대로 파이썬에서 빈 값을 DB에 넣을 때 빈 문자열과 None을 명확히 구분해서 적재해야 데이터 정합성이 깨지지 않는다.
- `for` / `while` & `break` / `continue`:
    - 엔지니어링 시 무한 루프 위험이 있는 while은 거의 쓰지 않는다.  
    수십만 건의 데이터 처리는 for문을 주로 사용. 잘못된 데이터(에러)를 만났을 때  
    로직을 멈출지(break) 건너뛰오 다음 데이터 처리할지(continue, 로그남김)을 결정하는데 주로 사용
- `range` : `range(시작, 끝, 간격)` 형태로 숫자를 생성
    - 리스트처럼 메모리에 모든 숫자를 올려두지 않고, 필요할때마다 숫자를 하나씩 출력하는 방식이라 메모리 효율이 좋음
- `if` : 조건식을 통한 참 거짓 제어문
    - 자바와 달라 파이썬은 <span style="background-color: #535311;">if에 boolean이 아닌 값을 하나만 넣어도 참과 거짓으로 자동 평가된다</span>
    - **False 나오는 값** : `None`, `0`, 빈 문자열(""), 빈 리스트([ ]), 빈 딕셔너리({ })
    - 나머지는 전부 True
        ```py
            # 자바인 경우
            if (data_list != None and len(data_list) > 0) 
                print("데이터가 있습니다");

            # 파이썬
            if data_list:
                print("데이터가 있습니다")
        ```


### 2. 문자열 처리와 슬라이싱 (데이터 정제의 핵심)

- 인덱싱과 슬라이싱(`[start:end:step]`)
    - 문자열, 리스트의 특정 부분 자름. (java의 substring()보다 강력?)
    - **파일 데이트 헨들링 시 파일명 날짜만 추출하거나 특정 구간 문자를 자를때 유용함**
    - 마이너스(-) 인덱싱을 지원하여 맨 뒤부터 자를 수 있음
- `문자열.strip()` : 양쪽 공백(또는 특정 문자) 제거
- `문자열.split()` : 특정 문자를 기준으로 문자열을 쪼개어 리스트로 반환함
- `",".join(문자열)` : 리스트의 요소들을 특정 문자로 이어 뭍여 하나의 문자열로 만듬
- `문자열.replace("특정 문자", "바꿀 문자", 바꿀 횟수(생략가능))` : 특정 문자를 다른 문자로 바꾼다.

```py
    # CSV 파일로 한 행이 해당 문자열로 들어올 시 이를 리스트로 반환하는 코드
    row_data = "  apple,,banana, cherry\n , Macbook Air, None"

    clear_data = [value.strip() for value in row_data.split(",")]

    print(clear_data) # ["apple", "", "banana", "cheery", "Macbook Air", "None"]
```
- `f-string` (형식 지정 문자열) : 자바의 String.format()을 대체하는 파이썬 기능. 문자열 앞에 f를 붙이고 내부 변수를 { }로 집어넣음

```py
    # 동적 쿼리, 벌크 인서트용 쿼리 작성 시 사용
    scheme_ym = "2026"
    sql = f"SELECT SCHEME_NM, CATEGORY1, VISIBLE_YN FROM TB_SCHEME_MST WHERE SCHEME_YN = '{scheme_ym}'"\
```



- 추가적으로 알아두면 좋은 기능
    - `len(문자열)` : 문자열 길이
    - `"order_01".startwith("order_")` : 특정 문자열로 시작되는지 True, False
    - `"order.csv".endWith(".csv")` : 특정 문자열로 끝나는지 True, False
