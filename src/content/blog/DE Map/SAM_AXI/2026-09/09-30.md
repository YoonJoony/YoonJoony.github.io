## 클래스

C 언어에는 클래스가 없음. 즉, 굳이 클래스가 없어도 프로그램을 충분히 개발 가능.  
파이썬으로 잘 만든 프로그램도 클래스를 사용하지 않은게 많음. 꼭 필요한 요소는 아님  

> 하지만 클래스를 적재적소 활용하면 이점이 있음

예를들어 계산기 프로그램이 있다고 가정.

### 함수로 개발
```py
# 함수를 이용한 계산기
result1 = 0
result2 = 0

def add1(num):
        global result1
        result += num
        return result

def add2(num):
        global result1
        result += num
        return result
```

계산기가 2대 이상이면 각 계산 결과를 저장해야하므로 전역변수와 함수를 계속 만들어야 함  

### 그럼 클래스는?

```py
class Calculator: # 클래스 이름 첫 글자는 대문자
        companyName = "삼성" # 클래스 변수
        # 생성자 함수
        def __init__(self): # 파이썬은 self 인자가 무조건 들어감
                self.result = 0 # 인스턴스 변수 : 객체마다가 가지는 고유의 변수
        
        def add(self, num):
                self.result += num
                return self.result

cal1 = Calculator()
cal2 = Calculator()
print(cal.add(2))
print(cal.add(4))

```

각 cal1, cal2 객체마다 각각의 역할을 수행하며 독립적인 값 유지.  
계산기 수가 늘어나도 객체 선언만 추가해주면 따로 함수나 전역변수를 추가할 필요가 없다.
