업로드된 파일에는 "성능"이라는 단어 하나만 있어서, 표로 정리할 내용이 없었습니다. 그래서 이 대화에서 앞서 조회한 가격과 벤치마크 수치를 기준으로 정리했습니다. 파일에 다른 내용이 있었다면 다시 올려 주세요.

| 모델 | 주된 목적 | 잘 맞는 작업 | 성능 근거 (BenchLM) | 가격 (입력/출력, 100만 토큰) |
|---|---|---|---|---|
| **Opus 5.5** | 가장 어려운 문제 해결 | 복잡한 추론, 대규모 코드 수정, 장시간 에이전트 작업, 난도 높은 분석 | 종합 85.43 (#1), SWE-bench Pro 89.9%, ARC-AGI-2 91.7% | $4 / $20 |
| **Sonnet 5.5** | 일상 업무의 주력 모델 | 코딩, 문서 작성·요약, 업무 자동화, 도구 호출이 많은 에이전트 | 종합 83.92 (#4), SWE-bench Pro 81.3%, Terminal-Bench 70.6% | $2 / $10 |
| **Fable 5.1** | 최상위 성능 (안전장치 강화) | 고난도 과학·연구 분석, 전문가용 추론 (생물·사이버·LLM 연구 관련 추가 안전장치 적용) | 종합 82.09 (#5), GPQA Diamond 93.4%, HLE 60.9% | $10 / $50 |
| **Haiku 5.5** | 빠르고 저렴한 대량 처리 | 분류, 태깅, 짧은 요약, 정보 추출, 실시간 응답, 대량 배치 작업 | 종합 64.19 (#37), Terminal-Bench 39.2% | $0.10 / $0.50 |
| **Mythos 5.1** | 제한된 기관 전용 | 현재 일반 공개 대상이 아니며, 소수 기관이 Project Glasswing에서 사용 | 공개 벤치마크 자료 없음 | $10 / $50 (접근 제한) |

**모델 선택 기준**
- 품질이 가장 중요하고 비용은 나중 문제라면 **Opus 5.5**입니다.
- 대부분의 업무는 **Sonnet 5.5**로 충분하며, 점수 대비 비용이 가장 좋습니다.
- 대량 처리나 빠른 응답이 필요하면 **Haiku 5.5**를 쓰고, 배치 API를 함께 쓰면 비용이 더 줄어듭니다.
- **Fable 5.1**은 최고 수준이 필요한 전문 연구 작업에 쓰지만, 비용이 Sonnet의 5배입니다.

이 표는 제3자 벤치마크(BenchLM)와 공식 가격표를 기준으로 한 정리입니다. 모델별 공식 용도 안내와 최신 가격은 [Claude 가격 안내](https://platform.claude.com/docs/en/about-claude/pricing?hsLang=en)에서 한 번 더 확인해 주세요.
